# Spotube

- [`extension/`](extension/README.md): a Chrome and Edge extension that adds a YouTube and YouTube Music search
  panel next to Spotify's web player. Start here.
- [`archive/web-app/`](archive/web-app/README.md): the Spotube Web site (Next.js on Cloudflare Pages). It was
  archived on 2026-10-12 and is no longer deployed from this repository.

Based on [Spotube](https://github.com/KRTirtho/spotube) by Kingkor Roy Tirtho.
