    Settings

    To search YouTube, this panel needs a free YouTube key from Google. You only do this once, and it doesn't cost anything.

    1. Open YouTube Data API v3 ↗, sign in with Google, create a project if it asks, and press Enable.
    2. Open Credentials ↗, choose Create credentials → API key, and copy the key.
    3. Paste it here and press Save.

    Spotube is not made by or connected to Spotify or YouTube. It uses YouTube's own player, so YouTube's ads may play in it.
